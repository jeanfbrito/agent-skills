What a cycle touches

2026-10-09

Human. Outside both worlds and the only brake: the loop never asks "continue?". Verdicts and held rows go in the journal.

Orchestrator. Spawns one new subagent per cycle with the fixed prompt, reads one status line back, spawns the next. Does no cycle work.

Cycle subagent. Starts empty. Everything it knows comes up through the brief, so no cycle carries the history of the last.

state.py, the door. Lock first: exit 3 is another live session, exit 4 is paused. A brief that says IN PROGRESS resumes from the last note.

Trail. One note the moment each step happens, never saved for the end, so a kill loses at most the step in progress.

Report. Not a separate job. Every note rebuilds it, so the trail is the live report.

Journal. Direction in one or two sentences, one gap row per feature area, each with a Done when.

Blind critic. One round for the whole queue with the last captures. A loss goes to below; each deficit becomes a sense check.

One idea. Marks welcome. Frame: modules.
